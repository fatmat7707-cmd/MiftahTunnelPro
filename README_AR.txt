مفتاح النفق الذكي - Miftah Tunnel Pro
الإصدار: 0.4.0

الوظائف:
- تطبيق Android أصلي بواجهة عربية.
- فحص حالة اتصال الإنترنت عبر Android ConnectivityManager.
- تحليل تشخيصي غير تخريبي لمعلومات الشبكة: عنوان الجهاز، البوابة الافتراضية، خوادم DNS.
- قراءة مؤشر Android الخاص ببوابة الدخول الأسيرة (Captive Portal).
- اختبار HTTPS قياسي محدود المهلة للتحقق من الاستجابة وإعادة التوجيه.
- استيراد ملف إعداد WireGuard بصيغة .conf وتحليله وتشغيل/إيقاف النفق بموافقة Android.

حدود الفحص:
- التحليل تشخيصي ولا يستغل الثغرات ولا يتجاوز المصادقة أو بطاقات الدفع.
- ظهور إعادة توجيه أو فشل اختبار الاتصال لا يثبت وحده وجود ثغرة؛ قد يكون نتيجة بوابة دخول أو سياسة شبكة أو انقطاع إنترنت.
- لا ينفذ التطبيق مسح منافذ أو تخمين كلمات مرور أو تغيير إعدادات الراوتر.

متطلبات البناء: JDK 17 وAndroid SDK 35 وGradle 8.9.
لا يحتوي المشروع على خادم VPN أو مفاتيح اتصال. يجب استيراد ملف إعداد صالح لخادم تملك حق استخدامه.
تشغيل VPN لا يلغي احتساب حصة أو وقت HotSpot ولا يتجاوز انتهاء بطاقة الإنترنت.
